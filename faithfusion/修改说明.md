# FaithFusion 模板快速上手指南（面向小白）

> 按照下面的步骤，就能把模板改成你的项目页面。整个流程只围绕一个核心文件 `index.html` 展开，所有素材都放在 `static` 目录里，非常直观。

---

## 1. 项目目录速览

| 目录/文件 | 用途 | 修改频率 |
| --- | --- | --- |
| `index.html` | 页面所有内容（文字+结构） | ✅ 每次都要改 |
| `static/videos/` | 所有 mp4/webm 视频 | ✅ 放自己的视频 |
| `static/images/` | 图片（封面、插图、pipeline） | ✅ 放自己的图片 |
| `static/css/index.css` | 页面样式 | 可选 |
| `static/js/index.js` | 交互逻辑（轮播、slider） | 可选 |

---

## 2. 文案类内容怎么改？

全部在 `index.html` 中按顺序出现，搜索对应标题就能定位。

1. **项目标题、作者、链接（开头 Hero 区）**  
   - 搜索 `publication-title` 修改标题  
   - `publication-authors` 内改作者和机构  
   - `publication-links` 内改按钮链接（Paper / arXiv / Video / Code / Data）

2. **摘要 Abstract（`<section class="section">` 第一块）**  
   - 我已留空：`<!-- TODO: 在这里填写摘要内容 -->`  
   - 直接把 `<p>` 中内容替换为你的摘要文字，支持多段落。

3. **Pipeline 占位**  
   - 在 Abstract 后面，加了 `Pipeline` 区块  
   - 推荐做法：  
     - 只展示图片：  
       ```html
       <img src="./static/images/pipeline.png" alt="Pipeline 示例">
       ```  
     - 展示视频：  
       ```html
       <video controls playsinline width="100%">
         <source src="./static/videos/pipeline.mp4" type="video/mp4">
       </video>
       ```  
   - 记得先把素材放进 `static/images/` 或 `static/videos/`

4. **其他文字段落**  
   - Visual Effects：描述你的视频亮点  
   - Matting / Animation / Related Links：可替换为你的实验或使用案例  
   - 修改方式同上，直接改 `<p>` 内容即可

5. **BibTeX**  
   - 底部 `#BibTeX` 区域，把模板换成你的 BibTeX 引用

---

## 3. 视频/图片如何替换？

通用原则：

- 先把素材放到 `static/videos/` 或 `static/images/`
- 然后在 `index.html` 对应 `<source>` 或 `<img>` 上改路径
- 使用相对路径：`./static/videos/xxx.mp4`

常见区域说明：

| 区域 | 定位方式 | 建议 |
| --- | --- | --- |
| 顶部 Teaser 视频 | 搜索 `id="teaser"` | 替换 `src` 即可 |
| 轮播视频 | 搜索 `results-carousel` 下面的 `<div class="item ...">` | 逐个改 `<source src=...>` |
| Dollyzoom / Matting / Replay | 搜索对应 `id="dollyzoom"` 等 | 可替换为你自己的实验证明 |
| 插图 | `<img src="./static/images/interpolate_start.jpg">` | 用自己的图替换 |

添加新视频示例：

```html
<video controls muted loop playsinline width="100%">
  <source src="./static/videos/my_demo.mp4" type="video/mp4">
  <!-- 兼容 webm，可再加一行 -->
  <!-- <source src="./static/videos/my_demo.webm" type="video/webm"> -->
</video>
```

添加新图片示例：

```html
<img src="./static/images/my_result.jpg" alt="结果示例" style="width:100%; border-radius:8px;">
```

## 4. 完整操作流程示例（推荐顺序）

1. 复制你的素材：  
   - 视频 → `static/videos/`  
   - 图片 → `static/images/`

2. 打开 `index.html`，按照顺序修改：  
   - 标题/作者/链接  
   - 摘要（写自己的内容）  
   - Pipeline（插入图或视频）  
   - 各个段落（Visual Effects 等）文字+对应视频  
   - BibTeX

3. 保存后本地预览（见第 6 部分），检查是否加载成功：
   - 视频播放、图片显示、文字无误  
   - 控制台无报错（F12 → Console）

4. 如果要上线，记得压缩视频、图片，减小加载压力。

## 5. 小贴士 & 常见问题

- **文件名要一致**：大小写、后缀必须和 `<source src=...>` 中完全匹配
- **路径一定以 `./static/...` 开头**，不要写绝对路径
- **视频静音 autoplay**：为了保证自动播放，建议加 `muted playsinline`
- **缓存问题**：改完后浏览器看不到变化，按 `Ctrl+Shift+R` 强制刷新
- **控制台报错**：按 `F12` 查看 Console，通常是文件路径错了
